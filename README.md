# שאלוני אפיון — Nina Studio

כלי לניהול שאלוני אפיון ללקוחות: דשבורד אדמין (מוגן בהתחברות) ליצירת שאלונים ומעקב תשובות, ועמוד שאלון ציבורי שנגיש רק דרך קישור ייחודי.

## הרצה מקומית

```bash
npm install
cp .env.example .env   # כבר קיים עם הפרויקט הנוכחי, אין צורך לשנות
npm run dev
```

## יצירת משתמשת אדמין

הטבלאות מוגדרות כך שרק משתמש מחובר (`authenticated`) יכול לגשת לדשבורד. כדי ליצור את המשתמשת שלך:

1. כניסה ל-[Supabase Dashboard](https://supabase.com/dashboard/project/sqfuordjznrgyvwpmmna/auth/users)
2. Authentication → Users → **Add user** → הכנסת אימייל וסיסמה (לוודא ש-"Auto Confirm User" מסומן)
3. כניסה לדשבורד עם אותם פרטים בעמוד `/login`

> חשוב: אני (קלוד) לא יכולה ליצור את המשתמש/סיסמה בשבילך — זו פעולה שצריך לבצע ידנית מטעמי אבטחה.

## דיפלוי ל-GitHub Pages

1. יוצרים ריפו ב-GitHub ודוחפים את התיקייה הזו אליו (ענף `main`)
2. Settings → Pages → Source: **GitHub Actions**
3. Settings → Secrets and variables → Actions → **Variables** → מוסיפים:
   - `VITE_SUPABASE_URL` = `https://sqfuordjznrgyvwpmmna.supabase.co`
   - `VITE_SUPABASE_ANON_KEY` = (המפתח הציבורי מתוך `.env.example`)
4. כל push ל-`main` יבנה וידפלוי אוטומטית (ר' `.github/workflows/deploy.yml`)

המפתחות האלה **אינם סודיים** — זה ה-anon key הציבורי של Supabase, וההגנה האמיתית היא ברמת ה-RLS בבסיס הנתונים (ר' למטה).

## ⚠️ Supabase Free Tier — "פרויקט נרדם"

בפרויקט Free Tier, אם אין שום פעילות במשך כשבוע, הפרויקט "נרדם" (pauses) והאתר יפסיק לעבוד עד שמעירים אותו. איך מעירים:

- **מהדשבורד**: נכנסים ל-[Project settings](https://supabase.com/dashboard/project/sqfuordjznrgyvwpmmna) ולוחצים "Restore project" (לוקח כדקה-שתיים)
- **דרכי**: פשוט מבקשים ממני "תעירי את פרויקט הסופאבייס" ואני יכולה להריץ את זה דרך ה-MCP

## מבנה הנתונים

- `surveys` — כותרת, `questions` (JSON: מערך של `{id, label, type, required}`), `public_token` (מזהה ציבורי ייחודי), תאריך יצירה
- `responses` — מקושר ל-`surveys` לפי `survey_id`, `answers` (JSON: `{questionId: value}`), תאריך עדכון אחרון

**הרשאות (RLS):**
- משתמש מחובר (`authenticated`, כלומר את) — גישה מלאה לשתי הטבלאות
- ציבור (`anon`, כלומר לקוחות עם קישור) — **אין** גישה ישירה לטבלאות (כדי שלא יהיה אפשר "לדפדף" בין שאלונים). הגישה היחידה היא דרך 3 פונקציות מוגבלות: קריאת שאלון לפי טוקן, קריאת תשובות קיימות לפי טוקן, ושמירת/עדכון תשובות לפי טוקן — כל אחת מהן פועלת רק על השאלון שהטוקן שלו תואם.

## הוספת שאלונים "חכמים" עם Claude Code

כרגע יצירת שאלון היא דרך טופס בדשבורד (הוספת שאלה, סוג תשובה קצרה/ארוכה, חובה/לא). אין עדיין אינטגרציה שמייצרת שאלות אוטומטית מתוך תיאור חופשי — אפשר להוסיף את זה בהמשך (למשל כפתור "הצעת שאלות" בעמוד יצירת שאלון שקורא ל-API של קלוד), אבל זה דורש שרת/edge function כדי לא לחשוף מפתח API בצד הלקוח. אפשר לדבר על זה כשלב הבא.
